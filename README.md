FamilyHub — Семейный органайзер

> Единое пространство для задач, покупок и бюджета всей семьи. Перестаньте теряться в семейных чатах — всё в одном месте.

📋 Описание проекта

Идея

В семьях и коммунах деньги уходят «в никуда»: кто-то платит за всех, кто-то забывает отдать, а в конце месяца оказывается, что непонятно, куда ушла половина зарплаты. Ссоры из-за финансов — одна из главных причин напряжения в быту.

FamilyHub — это прозрачная общая касса. Вы видите, сколько потратили, на что и кто сколько внёс. Общий бюджет становится не полем для конфликтов, а инструментом планирования.

Задачи и список покупок здесь — это контекст для трат. Например, купить молоко — это не просто задача, а расход, который сразу попадает в бюджет и не теряется. Так вы не забываете, на что ушли деньги.

Целевая аудитория:

Семьи с детьми-подростками — хотим дать карманные деньги и учить планировать расходы

Студенческие коммуны — важно делить счета за ЖКХ и продукты без обид

Пары — которые хотят копить на общие цели (ремонт, отпуск) и видеть прогресс

🖥 Ключевые Страницаы и функциональность

Для пользователя (роль: member)

| Страница               | Содержимое                                                                 |
|------------------------|----------------------------------------------------------------------------|
| **Дашборд**            | Сводка невыполненных задач, последние расходы, быстрый доступ к добавлению |
| **Список задач**       | Просмотр, поиск, фильтр по исполнителю/статусу, отметка о выполнении       |
| **Список расходов**    | Просмотр всех трат, фильтр по категориям и датам                           |
| **Статистика бюджета** | Графики расходов по категориям, динамика за месяц                          |
| **Личный кабинет**     | Редактирование профиля, смена пароля, просмотр своих задач и расходов      |

Для администратора семьи (роль: admin)

| Страница              | Содержимое                                                                   |
|-----------------------|------------------------------------------------------------------------------|
| **Управление семьёй** | Просмотр и удаление участников, генерация invite-кода                        |
| **Модерация**         | Редактирование/удаление любых задач и расходов (как «родительский контроль») |

Для гостя (неавторизованный)

| Страница                 | Содержимое                                                                  |
|--------------------------|-----------------------------------------------------------------------------|
| **Логин / Регистрация**  | Вход в аккаунт, регистрация с созданием новой семьи или вступлением по коду |

---

✨ Уникальные фичи

- **Auth** — авторизация и аутентификация участников семьи
- **Ролевая модель** — admin семьи может управлять участниками
- **Статусная модель** — `work` → `done` → `archived`
- **Статистика бюджета** — графики трат по категориям (еда, ЖКХ, развлечения, и т.д.)
- **Планирование**  интеграция с OpenAI для задач

1. Проверка состояния сервера (health check)                                            │ +
bash
curl http://localhost:5000/api/health

2. Работа с задачами (/api/tasks)                                                       │ +
Получить все задачи

bash
curl http://localhost:5000/api/tasks
Получить задачу по ID (например, 1)

bash
curl http://localhost:5000/api/tasks/1
Создать новую задачу (POST) – передаём JSON-объект

bash
curl -X POST http://localhost:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Купить хлеб",
    "description": "Купить батон в пекарне",
    "status": "work",
    "assigneeId": "u2",
    "creatorId": "u1",
    "familyId": "f1",
    "deadline": "2026-07-15"
  }'
Обновить задачу (PUT) – заменяем поля

bash
curl -X PUT http://localhost:5000/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{
    "status": "done"
  }'
Удалить задачу (DELETE)

bash
curl -X DELETE http://localhost:5000/api/tasks/1

FamilyHub — Семейный органайзер

> Единое пространство для задач, покупок и бюджета всей семьи. Перестаньте теряться в семейных чатах — всё в одном месте.

📋 Описание проекта

Идея

Семейный быт — это хаос: купить молоко, заплатить за коммуналку, вынести мусор, не забыть про день рождения бабушки. Всё тонет в чатах, голосовых сообщениях и забытых стикерах. **FamilyHub** решает эту проблему — это единый дашборд, где семья может ставить задачи, вести общий бюджет и планировать покупки.

Целевая аудитория

- **Семьи с детьми-подростками** — нужно делегировать задачи и учить финансовой грамотности
- **Студенческие коммуны / соседи** — совместное ведение быта и прозрачные расходы
- **Пары, живущие вместе** — чтобы перестать спрашивать «ты купил хлеб?»

🖥 Ключевые экраны и функциональность

Для пользователя (роль: member)

| Экран                  | Что можно делать                                                           |
|------------------------|----------------------------------------------------------------------------|
| **Дашборд**            | Сводка невыполненных задач, последние расходы, быстрый доступ к добавлению |
| **Список задач**       | Просмотр, поиск, фильтр по исполнителю/статусу, отметка о выполнении       |
| **Список расходов**    | Просмотр всех трат, фильтр по категориям и датам                           |
| **Статистика бюджета** | Графики расходов по категориям, динамика за месяц                          |
| **Личный кабинет**     | Редактирование профиля, смена пароля, просмотр своих задач и расходов      |

Для администратора семьи (роль: admin)

| Экран                 | Что можно делать                                                             |
|-----------------------|------------------------------------------------------------------------------|
| **Управление семьёй** | Просмотр и удаление участников, генерация invite-кода                        |
| **Модерация**         | Редактирование/удаление любых задач и расходов (как «родительский контроль») |

Для гостя (неавторизованный)

| Экран                    | Что можно делать                                                            |
|--------------------------|-----------------------------------------------------------------------------|
| **Логин / Регистрация**  | Вход в аккаунт, регистрация с созданием новой семьи или вступлением по коду |

---

✨ Уникальные фичи

- **Invite-код** — вступление в семью по ссылке/коду, никаких сложных приглашений
- **Ролевая модель** — admin семьи может управлять участниками, обычные пользователи не могут удалять бюджет
- **Статусная модель задачи** — `pending` → `done` → `archived`
- **Email-уведомления** — напоминание о дедлайне задачи за 2 часа
- **Статистика бюджета** — графики трат по категориям (еда, ЖКХ, развлечения, и т.д.)
- **Умное планирование** (опционально) — интеграция с OpenAI для автораспределения задач

🗂 Сущности системы

| Сущность     | Ключевые поля                                                                             |
|--------------|-------------------------------------------------------------------------------------------|
| **User**     | id, email, name, password_hash, role (admin/member)                                       |
| **Family**   | id, name, invite_code (уникальный код для приглашения)                                    |
| **Task**     | id, title, description, status (pending/done/archived), deadline, assignee_id, creator_id |
| **Expense**  | id, amount, category_id, note, date, user_id                                              |
| **Category** | id, name, icon (справочник категорий: food, utilities, entertainment и т.д.)              |

👤 User Stories

| Роль              | История                                                                                       |
|-------------------|-----------------------------------------------------------------------------------------------|
| **Пользователь**  | Как член семьи, я хочу создать задачу и назначить ответственного, чтобы никто не забыл о деле |
| **Пользователь**  | Как член семьи, я хочу отметить задачу выполненной, чтобы остальные видели прогресс           |
| **Пользователь**  | Как член семьи, я хочу добавить расход с категорией, чтобы вести общий бюджет                 |
| **Пользователь**  | Как член семьи, я хочу видеть график трат по категориям за месяц, чтобы анализировать бюджет  |
| **Администратор** | Как глава семьи, я хочу удалить участника, если он больше не живёт с нами                     |
| **Администратор** | Как глава семьи, я хочу редактировать любую задачу или расход, чтобы исправлять ошибки        |

🚀 Как запустить локально

# 1. Клонировать репозиторий
git clone https://github.com/n1k00ne/final-project.git
cd final-project

# 2. Создать .env файлы (примеры ниже)
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# 3. Запустить через Docker Compose
docker compose up --build

Приложение будет доступно:

Frontend: http://localhost:5173

Backend API: http://localhost:3000

Swagger: http://localhost:3000/api-docs

Переменные окружения (backend)

DATABASE_URL=postgresql://user:password@localhost:5432/familyhub
JWT_SECRET=your_secret_key
MAIL_HOST=smtp.gmail.com
MAIL_USER=your@gmail.com
MAIL_PASS=your_app_password
OPENAI_API_KEY=your_key (опционально)
